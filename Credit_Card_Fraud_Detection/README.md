# 💳 Credit Card Default Prediction using Machine Learning

## 📌 Project Overview

This project predicts whether a customer will default on their credit card payment in the next month using Machine Learning.

The model is trained using Logistic Regression after preprocessing and feature scaling.

---

## 📂 Dataset Features

- LIMIT_BAL
- SEX
- EDUCATION
- MARRIAGE
- AGE
- PAY_0 to PAY_6
- BILL_AMT1 to BILL_AMT6
- PAY_AMT1 to PAY_AMT6

Target Variable:

- default.payment.next.month
